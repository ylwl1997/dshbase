Plugins

Everything is a plugin.

DeepSeek Harness's defining idea: every capability is a plugin. Learn what a plugin is, write your first one, and register tools. Based on the official developer guide.

What is a plugin?

A Harness plugin is a TypeScript module that exports an apply function. The framework calls apply when it loads, passing a ctx (context object) through which you register capabilities:

import type { Context } from '@deepseek-ai/cordis'

export const name = 'my-plugin'

export function apply(ctx: Context) {
  // Register capabilities here.
}

That's the whole minimal plugin. Anything you register via ctx — event listeners, tools, timers — is cleaned up automatically when the plugin unloads.

Your first plugin

Create a local project and a plugin file:

mkdir -p scratch-plugin/src
// scratch-plugin/src/my-plugin.ts
import type { Context } from '@deepseek-ai/cordis'

export const name = 'hello-plugin'
export function apply(ctx: Context) {
  console.log('[hello-plugin] plugin loaded!')
}

Then create scratch-plugin/cordis.yml as a patch that inserts your local plugin (use the absolute path printed by pwd):

- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'

Start the Web UI with the patch:

pnpm dsh web --patch ./scratch-plugin/cordis.yml

Open http://127.0.0.1:3080 — on startup the terminal prints [hello-plugin] plugin loaded!.

Register a tool

Use defineTool to add a tool your agent can call. Replace my-plugin.ts:

import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const name = 'greet-tool'
export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.tools.register(defineTool({
    name: 'greet',
    description: 'Greet someone by name.',
    parameters: {
      name: { type: 'string', required: true, description: 'The name to greet' },
    },
    output: {
      schema: { type: 'string' },
      render: (_args, value) => [{ type: 'text', text: value }],
    },
    async execute(args) {
      return `Hello, ${args.name}!`
    },
  }))
}

Restart with pnpm dsh web --patch ./scratch-plugin/cordis.yml, open the Web UI, and send:

Use the greet tool to greet Ada.

The model calls greet and gets Hello, Ada! as the tool result.
