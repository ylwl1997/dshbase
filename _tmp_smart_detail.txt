########## timeout/config regs detail 3900-4100 ##########
   Bit[12]：忙状态时交换数据接收禁止配置；若忙状态时交换数据接收禁止配置为‘0’
时，对于外部 NC 对本地处于忙状态接收子地址发起的访问时，控制流 NT 接收数据并
写入到由子地址存储地址配置表制定的 RAM 区；
   若忙状态时交换数据接收禁止配置为‘1’时，对于外部 NC 对本地处于忙状态接收子
地址发起的访问时，控制流 NT 舍弃接收的交换数据；
   Bit[13]: 保留；

6.5.2 长/短报文工作模式
   当第 1/2/3/4 路 SmartNC 配置寄存器的 Bit[10]配置为'0'时，SmartNC 处于在
长报文发送模式。在该模式下，SmartNC 单次可发起传输的数据量范围为[1,4G-1]
字节，数据接收方应该是工作在长报文接收模式的 SmartNT；工作在长报文模式

                         第 150 页
方向是单向的，即数据只能由 SmartNC 传向 SmartNT，不支持 SmartNT 向
SmartNC 传输数据。
    当第 1/2/3/4 路 SmartNC 配置寄存器的 Bit[10]配置为'1'时，SmartNC 处于在
短报文发送模式。在该模式下，SmartNC 单次可发起传输的数据量范围为[1,512]
字节，支持双向数据传输，传输配对 NT 可以是控制流 NT、或工作在短报文接
收模式的 SmartNT。

8.1.1 芯片 ID

    JLK1263 在 GLink 总线中参与数据传输时的 ID 号通过 IO 管脚 ID 配置，其
中高 8 位为网络域号，低 4 位为端口号。芯片 ID 奇校验有效，奇校验位为 ID_PAR，
芯片 ID 与芯片 ID 奇校验位按位异或值应为‘1’，否则不能正常通信。


8.1.2 安全模式

    JLK1263 通过 IO 管脚 SAFE_MODE 选择芯片上电时，是否使能安全模式，
SAFE_MODE 接高电平时，使能安全模式；SAFE_MODE 接低电平，禁止安全
模式。
    安全模式可保证配置参数的安全性，在安全模式下，芯片根据冗余控制架构
及设定的控制源 ID，对发起配置访问的控制源的 ID 号进行校对，校对通过的配
置指令有效，否则舍弃配置指令。除默认的控制源外，芯片允许设置 2 份白名单，
白名单中 ID 也可以对芯片进行配置。确认 ID 无误的配置指令有效，否则配置
指令无效。
    非安全模式下，任何网络终端均可对 JLK1263 进行配置，所有配置指令均
有效。


8.1.3 冗余模式

    JLK1263 通过外部 IO 管脚 VOTE 配置芯片上电时的冗余控制架构，安全模
式使能时，冗余控制架构生效，支持非冗余模式、三冗余模式。冗余模式的种类
决定了允许几个控制源对芯片进行配置。

8.1.5 环节点模式

  JLK1263 通过 IO 管脚 LOOP_EN 设置芯片的环节点模式，LOOP_EN 接低
电平时，芯片接入交换机；LOOP_EN 接高电平时，芯片接入环网络。环网络中，
芯片可对数据帧进行转发，交换机网络中不涉及转发。


8.1.6 IO 输出默认值配置

  JLK1263_C 支持 64 路 IO 输出，管脚名称为 PWM0~63，通过管脚 SIG_DEF
设置 PWM0~63 的上电默认值，16 路 IO 输出为一组，SIG_DEF 接高电平时默认
输出高电平，SIG_DEF 接低默认输出低电平。
  Bit0: 1~16 路 IO 输出（PWM0~15）默认值；
  Bit1: 17~32 路 IO 输出（PWM16~31）默认值；
  Bit2: 33~48 路 IO 输出（PWM32~47）默认值；
  Bit3: 49~64 路 IO 输出（PWM48~63）默认值。

8.2.2 电平输出
  电平输出是一种特殊的 PWM 输出，当 PWM 输出的占空比为 100%时，即

比参数 PWM_pls_param 为 0x0000，频率参数不需配置。
