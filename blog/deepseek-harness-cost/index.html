DeepSeek Harness cost & caching: why harness choice moves the bill 7x

August 14, 2026 · dshbase

DeepSeek's models are already cheap per token — but the harness you run them in can multiply the bill anyway. A coding agent re-sends the system prompt, tool definitions, conversation history, and code on every step. How well the harness reuses that work is what shows up on the invoice.

Prefix caching: skip what the model already read

Modern providers implement automatic prefix caching: if the beginning of a request matches a previous one (system prompt, tool definitions, history), that part is reused instead of recomputed. The cache hit rate is the share of input tokens that reused prior computation — the higher it is, the cheaper each call.

The catch: a changed timestamp, a reordered tool, or rewriting earlier content can invalidate the cache and force a full recompute. Simple, append-only sessions hit the cache far more often than chaotic ones.

Measured: a third-party agent hit 99.93% hit rate

Community measurements of an open-source agent called Pi (on GitHub, ~86k stars) running DeepSeek reported a cache hit rate around 99.93% — a miss rate of 0.07%. Pi's design is deliberately minimal: only four default tools (read, write, edit, run), with everything else opt-in, and sessions that keep appending rather than rewriting. Reported impact: roughly ¥19 per 1B tokens with caching vs ¥900+ without.

Same model, different harness: up to 7x

A third-party benchmark (Composio) ran DeepSeek V4 Flash across 8 agent harnesses on real tasks. The average cost per successful task ranged widely:

  • Cheapest: Pi at ~$0.028 per successful task.
  • Most expensive: Claude Code at ~$0.195 — nearly 7x Pi.

That gap isn't a knock on Claude Code's quality — it's a workflow built and tuned for Claude models, so it doesn't fully capture DeepSeek's low-cost, cache-friendly design. Same model, different harness, very different bill.

What this means for DeepSeek Harness

DeepSeek Harness's philosophy aligns with this: a minimal-tool, everything-is-a-plugin architecture keeps the active surface small, and PTC mode (programmatic tool calling) keeps intermediate data out of the model context to save tokens. The lesson applies broadly: pick a harness that reuses context, not one that churns it.

Numbers above are community-reported third-party measurements, not official DeepSeek benchmarks — verify current pricing before committing.
