DeepSeek Harness modes: which preset should you use?

August 14, 2026 · dshbase

DeepSeek Harness ships four built-in agent presets (modes). Switching modes doesn't change model capability — it changes which tools the agent holds and what rules it runs by. Here's what each one is for.

1. Standard mode

The fully-loaded coding agent: file editing, shell, search, skills, planning, goals, sub-agents, and workflows. This is the default product shape — the direct counterpart to Claude Code and Codex. Most people should use this.

2. PTC mode (Programmatic Tool Calling)

PTC wraps tools as a code API: the model writes a TypeScript program that chains a dozen steps and runs them in one shot, returning only the final result. Intermediate data stays in the execution environment — it never enters the model context. The goal is saving tokens. Built for heavy users who treat the agent as a batch tool and care about cost.

3. Minimal mode

Just two tools: a persistent bash shell and a file editor. The bet is that a strong model can do most coding with a terminal plus file editing — no scaffolding. Run this when you want to compare model ability without harness interference. (Notably, DeepSeek's V4 Flash release notes said it was benchmarked using Harness minimal mode.)

4. Create mode

Used to build custom agent presets. It has all of standard mode plus runtime checks, plugin experimentation, and preset-authoring guidance — "the mode that makes modes," for plugin developers.

How to think about modes

A preset is the set of plugins an agent runs with: its tools, prompts, and capabilities. You can copy an existing preset and tweak it, or use Create mode to have the agent build one for you. Different presets expose different slash commands — for example, minimal mode has only a goal command, while standard/code/create include conversation compression, goals, and planning.

You can even build presets for non-coding work — e.g., a "writing workspace" preset that loads a folder of skills and custom prompts.
