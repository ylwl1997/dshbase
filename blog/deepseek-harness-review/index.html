DeepSeek Harness first impressions: 37k stars, V4 Pro pricing, and the "make your own wrench" mode

August 14, 2026 · dshbase · data & screenshots used with permission from 卡兹克's review

DeepSeek Harness shipped right after DeepSeek V4 Pro — and the community's reaction was fast. Within days the repo hit ~37,000 stars. It's a polarizing tool: some call it the future, others call it too raw. This review breaks down what it actually is, what it costs now, and what's worth using.

The numbers that matter

  • ~37k GitHub stars within days of release.
  • V4 Pro cache pricing rose 12x at cache-hit prices.
  • Peak output reached ~¥27 per unit — pricing started at 3x across the board.

That price jump matters. At peak output, V4 Pro's API cost advantage vs GLM and Qwen 3.8 Max has narrowed significantly — and with GLM-5.3 reportedly coming at unchanged pricing, V4 Pro's "price killer" reputation is under pressure from the API-pricing side alone.

The four modes, from a hands-on angle

Don't overthink the four modes — they're template presets for how the agent is assembled.

  • Standard — full coding agent (file read/edit, shell, search, skills, planning, goals, sub-agents, workflows). Just use this unless you have a reason not to.
  • PTC (Programmatic Tool Calling) — same capabilities as standard, but the model writes a TypeScript program and chains many tool operations inside one run_code. What used to take five model round-trips (read, search, filter, parallel calls, combine) can collapse into one execution — fewer round-trips, fewer tokens. Requires stable code-planning from the model and is harder to debug; skip it until you're hitting repetitive tool round-trips.
  • Minimal — just two tools: a persistent bash and a file editor, with the system prompt frozen to "you are a helpful software engineering assistant". Meant for model benchmarking on a clean harness. Don't use it day-to-day.
  • Create — standard capabilities plus the ability to inspect the running Cordis environment, experiment with plugins in-memory, and build new presets. This is the "make your own wrench" mode: you can ask the agent to build a read-only security-audit preset, or a research agent with company search and three custom skills — and it can even create a missing plugin and hot-attach it to the running flow.

Append-only session logs: a hidden developer win

Sessions are designed as an append-only event log — system prompts, user messages, reasoning, tool calls and results, permission changes, context injections, compression, and sub-agent scheduling all become events. The next turn's history is re-derived from that log. The payoff is observability: when an agent fails or loops, you can trace exactly where it went off the rails, and runs are reproducible — valuable for research and auditing.

Not locked to DeepSeek — and a healthy plugin ecosystem

The honest take

DeepSeek Harness is a fascinating system and the plugin concept is strong — but as a product it's developer-unfriendly: dense terminology, a steep learning curve, and a raw UI will push away casual users. That's the trade-off of a team that prioritizes research and exploration — their slogan is literally "探索未至之境" (explore the undiscovered).
