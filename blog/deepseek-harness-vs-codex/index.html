"It doesn't want to be the next Codex" — DeepSeek Harness vs Codex

August 14, 2026 · dshbase

Calling DeepSeek Harness "a DeepSeek version of Codex" is the first thing most people say — and the thing the project most pushes back against. The difference isn't cosmetic; it's a different model of how an agent should be configured.

The key difference: agent presets, not scenarios

Codex-class products separate modes by scenario — daily/office, office/code, and so on. DeepSeek Harness instead uses Agent presets: a preset is the exact set of plugins an agent runs with — its tools, prompts, and capabilities assembled into a profile.

The four built-in presets (standard, code, minimal, create) are just starting points. You copy one, tweak it, or use Create mode to build a new one — including non-coding presets, like a writing workspace that loads a folder of skills and custom prompts.

Rebuildable sessions

Codex-class sessions are opaque. DeepSeek Harness sessions are append-only event logs: system prompts, user messages, reasoning, tool calls and results, permission changes, context injections, compression, and sub-agent scheduling all become events. The model's next-turn history is re-derived from the log. When an agent fails or loops, you can trace the exact step where it went off the rails — an observability win Codex doesn't expose.

The plugin model

Where Codex lets users customize Skills and MCP but keeps the rest baked in, DeepSeek Harness makes everything a plugin — the UI, the tools, the workflow. You can even hot-attach a newly created plugin to a running session. That's a different relationship with the tool: you're assembling an agent, not renting one.

Model flexibility

DeepSeek Harness isn't locked to DeepSeek models. It supports directory providers and custom providers (base URL, protocol, model list), so you could run GLM, or another model, inside the harness. Codex is tied to OpenAI models.

What this means practically

  • Choose Codex-class tools if you want a polished, scenario-driven product with minimal configuration.
  • Choose DeepSeek Harness if you want to assemble presets, rebuild sessions, audit every step, and extend the agent itself.
