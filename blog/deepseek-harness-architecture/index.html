The most ambitious agent open source of the year: an agent that modifies itself

August 14, 2026 · dshbase

The first wave of reactions to DeepSeek Harness split the community. Some call it the future of agents; others call it too raw. Both are right — because DeepSeek isn't shipping a finished product, it's shipping a framework where the agent can rebuild itself.

Agent = Model + Harness

The core formula is Agent = Model + Harness. The model reasons; the harness connects that brain to files, terminals, search, and tools. What's radical about DeepSeek Harness is that every part of the harness is a plugin — tools, skills, sessions, sandboxes, the agent loop, sub-agents, workflows. Nothing is baked in that you can't swap.

Think modular phone: every component is replaceable. The only real core is Cordis, a deliberately minimal kernel that does plugin loading, unloading, and dependency management — and nothing else.

Why the kernel matters: self-modifying agents

Cordis guarantees two properties that make self-modification safe:

  • Temporal composability — when a plugin unloads, its side effects are fully undone.
  • Spatial composability — a plugin re-resolves its dependencies as siblings appear, disappear, or change.

Because the agent can hot-swap plugins without corrupting state, it can extend itself while running. That's the real bet: an agent that notices it lacks a capability, builds the plugin, and attaches it to its own running flow.

Create mode: the "make your own wrench" pattern

The Create mode exposes this directly. You can tell the agent:

"Build a read-only, security-audit-only mode that can read code but never modify files."

…or ask it to inspect its own loaded plugins, notice one is missing, create it on the spot, and hot-attach it. The metaphor used by reviewers: the agent realizes it has no wrench, so it forges one, attaches it to its hand, and keeps working.

A real test: writing a novel

One hands-on test was a creative task — a 100,000-word web-novel plot (a disciple sweeping a sect's courtyard for ten years, sweeping out an ancient master's hall). In Create mode, the agent didn't just write: it rewrote and expanded the prompt into a richer brief first, then structured the work. The point isn't the output quality — it's that the harness let the agent shape its own tasking pipeline rather than just answering.

Even the UI is a plugin

Because everything is a plugin, even the Web UI is a plugin. Community members already swapped in custom skins without touching core capabilities (sessions, models, tools, sandbox) — a one-command install/switch, with one-click restore.
