How a minimal harness hits a 99.93% cache hit rate on DeepSeek

August 14, 2026 · dshbase

The cheapest way to run DeepSeek isn't just a cheap model — it's a harness that reuses the work the model already did. Community measurements of the open-source agent Pi showed a 99.93% prefix-cache hit rate (0.07% miss). Here's why.

The cost driver: every step resends the past

A coding agent sends the system prompt, tool definitions, conversation history, and code on every step. As a task runs longer, requests grow — and most of what gets sent, the model has already processed before. That's where automatic prefix caching helps: the provider remembers the computed prefix, and if the system prompt, tool definitions, and history are unchanged, it reuses them and only processes the new tail.

The cache hit rate is the share of input tokens that reused prior computation. Higher hit rate = less recomputation = lower cost.

Why caching is fragile

The trap: add a timestamp, reorder a tool, or rewrite earlier content and the cache misses, forcing a full recompute. Cache-friendly harnesses are those that keep the request prefix stable.

Pi's recipe: small tools + append-only sessions

Pi is deliberately minimal: by default it gives the model just four tools — read file, write file, edit file, run command. Everything else (plan mode, sub-agents, MCP, Git checkpoints, permissions) is opt-in. And sessions append rather than rewrite, so the earlier context rarely changes.

The result, reported by a developer running DeepSeek through Pi: a cache hit rate of ~99.93% (miss rate 0.03–0.07%). Roughly ¥19 per 1B tokens with caching vs ¥900+ without.

The 7x gap: same model, different harness

A third-party benchmark (Composio) ran DeepSeek V4 Flash across 8 agent harnesses on real tasks. Average cost per successful task:

  • Pi: ~$0.028 (cheapest)
  • Claude Code: ~$0.195 (most expensive, nearly 7x Pi)

Same model, different harness, 7x cost difference — driven largely by how well each reuses context.

What to take away

  • Minimal tool sets and append-only sessions are the biggest levers for cache hits.
  • DeepSeek Harness aligns with this: small active surface, everything-as-plugin, and PTC mode keeps intermediate data out of context.
  • Measure your own hit rate before assuming your harness is cheap.
