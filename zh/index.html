什么是 DeepSeek Harness？

DeepSeek Harness（DSH）是 DeepSeek 于 2026 年 8 月发布的开源 Agent 框架（开发者预览版），核心理念是 Agent = Model + Harness：模型负责推理，Harness 负责把模型接入真实世界（文件、终端、浏览器）。它的特别之处在于——Harness 的每个组成部分都是插件，包括 UI 本身。

🧩 一切皆插件

工具、技能、会话、沙箱、Agent 循环都是 npm 插件，可自由拼装替换。

🚀 开源 & 自进化

基于 Cordis 内核，Agent 可在运行中装卸插件、改造自身。

📦 npm 生态

官方 + 社区 120+ 个插件，标注 dsh-plugin 话题即可被发现。

快速 开始

一条命令启动 Web UI（详见安装指南）：

npx @deepseek-ai/dsh web
  1. 浏览器打开 http://127.0.0.1:3080，填入 DeepSeek API Key。
  2. 设置 → 模型 配置模型，选择工作区 添加项目目录。
  3. 发送任务，Agent 开始读写文件、运行命令、执行任务。

常见问题

DeepSeek Harness（DSH）是什么？

DeepSeek 于 2026 年 8 月发布的开源 Agent 框架（开发者预览版），核心理念「一切皆插件」。每个能力都是 npm 插件，可自由插拔，对标 Claude Code / Codex。

怎么安装 DeepSeek Harness？

运行 npx @deepseek-ai/dsh web，打开 http://127.0.0.1:3080，填入 DeepSeek API Key 即可。也可从源码构建。

DSH 和 Claude Code 有什么不同？

架构上：DSH 是「一切皆插件」（npm），Claude Code 以 MCP 为中心。详见完整对比。

DSH 免费吗？

DSH 开源免费；底层 DeepSeek API（V4 Pro 等）按官方定价收费。
