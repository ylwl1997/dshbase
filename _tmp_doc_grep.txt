1 PCIE转axi 寄存器说明

0x00 地址
写入的32位数据  支持读写 能读出上一次写入的数据
0x04 地址
可从此寄存器读出emif写32位数据 数据 只读 

0x08 地址
写入的19位地址数据位数据   支持读写  能读出上一次写入的地址数据

0x0c 地址 操作设置控制寄存器

BIT 0   只写    写使能  写1 根据当前0x08 地址数据和0x00 的数据写入emif   写0 无操作
BIT 1   只写    读使能  写1 根据当前0x08 地址数据读出emif 数据并放到FPGA 内部fifo后BIT20 rxfifo_empty 值位0时  可对bit8 写1将数据锁存到0x04地址上  写0 无操作
BIT 2  只写 清除读数据有效位  （目前无功能）
BIT3   只写 写bit4~bit7 有效 写入EMIF_CE_N 片选  
BIT4~BIT7 读写   写入片选信号EMIF_CE_N[0:3]  0x7  为操作fpga内部寄存器 0xb为操作1263寄存器 
BIT8 axi_rxfifo_rd_en 只写 读数据使能，将fifo中的数据读取到0x01寄存器上
BIT 8~BIT 15 预留  

BIT16    fifo_empty    只读   判断写操作是否完成 为1 是写操作完成 
BIT17    fifo_full      只读   1写fifo满，需要等fifo位位0之后才能写
BIT18    tx_wr_rst_busy 只读   tx fifo 写状态 1 忙 0 空闲
BIT19    tx_rd_rst_busy  只读  tx fifo 读状态 1 忙 0 空闲
BIT20    rxfifo_empty   只读   rx fifo 状态 1空  0 非空，fifo里面有数据
BIT21    rxfifo_full     只读   rx fifo 状态 1满  0 非满 
BIT22    rx_wr_rst_busy 只读   rx fifo 写状态 1 忙 0 空闲
BIT23    rx_rd_rst_busy  只读   tx fifo 读状态 1 忙 0 空闲    
 
BIT19~BIT32 预留

0x10 地址
BIT0： rst_en   读写 复位 设置0 拉低复位信号    设置1 释放复位信号，此
位为1才能开始工作

2 fpga emif 模块寄存器
x0000 - 0x003C: 主要是配置和查询，比如设置发多少数据、看发完没、看FIFO里有多少数据。
x1000 / 0x2000: 是写数据的入口。
x3000: 是读数据的出口。
x4000+: 是系统控制，如复位和模式选择。

控制与状态寄存器 (0x0000 - 0x003C)
地址 (Hex)
参数名称
读/写
功能描述
0x0000
P_CTRL_REGISTER
读/写
控制寄存器。写：用于触发发送请求。
Bit[0-3] 触发 NC1-NC4 发送，
Bit[4-7] 触发 NT1-NT4 发送，
Bit[8-15] 触发对应的读请求。读：读取当前的请求状态标志位。
0x0004
P_STATUS_REGISTER
读/写
状态寄存器，只读：
Bit[0-7] 指示 NC/NT 任务是否完成；
Bit[8-15] 指示 RC FIFO 中的数据源类型；
Bit[16-23] 指示 SmartNC/NT 的错误标志。写：写 1 可清除 Bit[0-7] 的完成标志和 Bit[16-23] 的错误标志。
0x0008
P_NC1_SEND_NUM
写
设置 NC1 通道发送的数据数量（32位）。
0x000C
P_NC2_SEND_NUM
写
设置 NC2 通道发送的数据数量（32位）。
0x0010
P_NC3_SEND_NUM
写
设置 NC3 通道发送的数据数量（32位）。
0x0014
P_NC4_SEND_NUM
写
设置 NC4 通道发送的数据数量（32位）。
0x0018
P_NT1_SEND_NUM
写
设置 NT1 通道发送的数据数量（低9位有效）。
0x001C
P_NT2_SEND_NUM
写
设置 NT2 通道发送的数据数量（低9位有效）。
0x0020
P_NT3_SEND_NUM
写
设置 NT3 通道发送的数据数量（低9位有效）。
0x0024
P_NT4_SEND_NUM
写
设置 NT4 通道发送的数据数量（低9位有效）。
0x0028
P_WD_FIFO1_WR_NUM

0x002C
P_WD_FIFO2_WR_NUM

数据写入与发送寄存器 (0x1000 - 0x3000)
地址 (Hex)
参数名称
读/写
功能描述
0x1000
P_FIFO1_WRITE_REGISTER
写
FIFO1 数据写入。向此地址写入数据，会将 EMIF_ED_IN[15:0] 写入到 WD_FIFO1 中。
0x1004
P_FIFO1_SEND_RAM_WRITE
写
FIFO1 发送 RAM 写控制。触发 FIFO1 关联的发送 RAM 的写使能和写地址更新逻辑。
0x2000
P_FIFO2_WRITE_REGISTER
写
FIFO2 数据写入。向此地址写入数据，会将 EMIF_ED_IN[15:0] 写入到 WD_FIFO2 中。
0x2004
P_FIFO2_SEND_RAM_WRITE
写
FIFO2 发送 RAM 写控制。触发 FIFO2 关联的发送 RAM 的写使能和写地址更新逻辑。
0x3000
P_DATA_READ_REGISTER
读
数据读取寄存器。读取此地址会触发 RD_FIFO1 或 RD_FIFO2 的读使能，并返回读出的数据（拼装在 r_emif_read_data 中）。

系统配置与复位寄存器 (0x4000 - 0x5000)
地址 (Hex)
参数名称
读/写
功能描述
0x4000
P_JLK_RESET_REGISTER
写
JLK 复位控制。写入 Bit[0] 控制 I_RESET_N 信号，用于复位外部接口逻辑。
0x4004
P_FIFO_SELECT_REGISTER
读/写
FIFO 通道选择。写：配置 FIFO1/2 的读写通道选择信号（r_fifo1_wr_sel, r_fifo1_rd_sel 等）。读：读取当前的通道选择配置。
0x4008
P_CLK_FREQ_SEL_REGISTER
读/写
时钟频率选择。写：设置 r_clk_freq_sel（4位），用于选择接口时钟频率。读：读取当前的频率选择配置。
0x5000
P_FIFO_RESET_REGISTER
写
FIFO 复位。写入 Bit[0] 为 1 时，产生一个脉冲信号 FIFO_RST，用于复位内部 FIFO。

参数名称

功能描述
