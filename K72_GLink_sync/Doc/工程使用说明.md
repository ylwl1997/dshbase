# K72 GLink 工程使用说明

## 1. 项目概述

本工程是 K72 GLink 板卡的测试程序, 基于 XDMA + PCIe 接口, 通过 INDIRECT BRIDGE 间接访问 FPGA 和 JLK1263 的 EMIF 总线寄存器。程序参照 `serial` 串口卡工程的三层架构设计, 提供完整的寄存器配置、链路监控和数据传输测试。

**硬件平台**:
- K72 GLink 板 (Kintex-7 xc7k410t-ffg900 FPGA + JLK1263N 协议芯片)
- XDMA PCIe 驱动 (Linux)
- QSFP 光模块 + 光纤

**软件平台**:
- Linux (内核 4.19.90, ARM64)
- GCC 7.3.0
- XDMA 用户驱动 (xdma.ko)

## 4. 寄存器访问原理

### 4.1 XDMA INDIRECT BRIDGE

通过 XDMA BAR 的 4 个寄存器间接访问 EMIF 总线:

| BAR 偏移 | 名称 | 功能 |
|---------|------|------|
| 0x10000 | EF_WR_ADDR | 写数据寄存器 |
| 0x10004 | EF_RD_ADDR | 读数据寄存器 |
| 0x10008 | EF_AR_ADDR | 19位 EMIF 地址 |
| 0x1000C | EF_ST_ADDR | 状态/控制寄存器 |

**写流程**: `EF_AR_ADDR <- addr` -> `EF_WR_ADDR <- data` -> `EF_ST_ADDR <- WR_EN`
**读流程**: `EF_AR_ADDR <- addr` -> `EF_ST_ADDR <- RD_EN` -> 轮询 RX_EMPTY -> `EF_ST_ADDR <- FIFO_RD_EN` -> `EF_RD_ADDR -> data`

### 4.2 EMIF 地址空间

EMIF 地址 19 位, bit18 区分 REG/MEM 空间:

```
REG(x):  emif_addr = x & 0x3FFFF           (bit18=0)
MEM(x):  emif_addr = 0x40000 | (x & 0xFFFF) (bit18=1)
```

### 4.3 片选 CE_N[3:0]

| CE_N | 访问对象 | 地址范围 |
|------|---------|---------|
| 0x7  | FPGA 内部寄存器 | 0x0000-0xF000 |
| 0xB  | JLK1263 (REG+MEM) | REG 0x00-0x0F, MEM 0x000-0xFFF |

## 5. 寄存器定义

### 5.1 FPGA 寄存器 (CE_N=0x7)

| 地址 | 名称 | 读/写 | 功能 |
|------|------|------|------|
| 0x0000 | P_CTRL_REGISTER | R/W | 控制: 触发 NC/NT 发送 |
| 0x0004 | P_STATUS_REGISTER | R | 状态: NC/NT 完成标志 |
| 0x0008-0x0024 | P_NCx/NTx_SEND_NUM | W | 各通道发送数量 |
| 0x0028-0x003C | P_xx_FIFO_WR_NUM | R | FIFO 已写入量 |
| 0x1000 | P_FIFO1_WRITE_REGISTER | W | FIFO1 数据写入 |
| 0x2000 | P_FIFO2_WRITE_REGISTER | W | FIFO2 数据写入 |
| 0x3000 | P_DATA_READ_REGISTER | R | 接收数据读出 |
| 0x4000 | P_JLK_RESET_REGISTER | W | JLK 复位 (bit0=I_RESET_N) |
| 0x4004 | P_FIFO_SELECT_REGISTER | R/W | FIFO 通道选择 |
| 0x4008 | P_CLK_FREQ_SEL_REGISTER | R/W | SerDes 速率 (默认 0x5=2.5G) |
| 0x5000 | P_FIFO_RESET_REGISTER | W | FIFO 复位 |
| 0xF000 | P_DEBUG_REGISTER | R | FIFO 上溢/下溢错误 |

### 5.2 JLK1263 REG 寄存器 (CE_N=0xB, bit18=0)

| 地址 | 名称 | 功能 |
|------|------|------|
| 0x00 | NODE_ID | 节点ID (bit15=使能) |
| 0x02 | WORK_MODE | 工作模式 (ctrlNC1/ctrlNT等) |
| 0x03 | CHANNEL_EN | A/B通道使能 |
| 0x07 | TIMESTAMP | 时间戳间隔 |
| 0x0A | CH_A_STATUS | A通道状态 (bit0=活动, bit1=LINK) |
| 0x0B | CH_B_STATUS | B通道状态 |

### 5.3 JLK1263 MEM 空间 (CE_N=0xB, bit18=1)

| 偏移 | 名称 | 功能 |
|------|------|------|
| 0x000-0x0FF | SPACE_INIT | 初始化区 (填 0xFFFF) |
| 0x100-0x105 | NC1_MAP | NC1 内存映射 |
| 0x120-0x123 | NT_CH_MAP | ctrlNT 通道映射 |

## 7. 测试项说明

### 7.1 交互式收发测试
- 选择节点角色 (NC/NT/NC+NT)
- 选择通道 (A/B)
- 子菜单: 发送/接收/查LINK/打印寄存器

### 7.2 A↔B 通道自环测试
- **硬件要求**: K72 板 A通道光口 ↔ B通道光口 光纤直连
- 自动执行: 复位 -> 配置JLK -> 初始化MEM -> 等LINK UP -> NC1发送 -> NT接收 -> 校验数据

### 7.3 API 功能测试
逐个验证 16 个 API 函数, 每项独立开关设备, 互不干扰。

### 7.4 LINK 状态监控
每 2 秒采样一次 A/B 通道 LINK 状态, 持续 30 秒。

## 8. 常见问题

### Q1: 设备打开失败
- 检查 `/dev/xdma0_user` 是否存在
- 检查 PCIe 设备是否被系统识别: `lspci | grep Xilinx`
- 检查 xdma.ko 是否已加载: `lsmod | grep xdma`

### Q2: EMIF 读写超时
- 检查 BRIDGE 复位是否释放 (0x10 寄存器 = 1)
- 检查 CE_N 片选是否正确

### Q3: LINK 一直 DOWN
- 检查光纤方向 (A的TX接B的RX)
- 检查 SerDes 速率 (FPGA 0x4008)
- 检查光模块类型

### Q4: MEM 空间读写不一致
- 两次 emifr 之间加延时 (RX FIFO 时序)
- 确认 bit18 地址位正确 (MEM_ADDR 宏)
